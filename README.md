# You Could Use A Nap

Requires [Egg v2](https://github.com/aksommerville/egg2) to build.

For [GDEX Game Jam 2026](https://itch.io/jam/gdex-game-jam-2026), theme "REST".

Guide the cats to the sunbeams so they can take a nap.
